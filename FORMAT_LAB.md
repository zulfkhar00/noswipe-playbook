# Format lab

Every posted video gets a row. Fill the metrics in from Instagram / TikTok Insights 48–72 h after posting.

**Decision rule (set before posting):**
- **Double down** if a format beats the account median on at least 2 of: link clicks per 1,000 views, % watched, shares per 1,000.
- **Iterate the hook** if viewers drop early but the ones who stay watch to the end.
- **Kill** if it's bottom on all three across both episodes.
